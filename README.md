# 📊 Peripheral Sales Dashboard

This project is a **Power BI dashboard** created to analyze and understand sales data for computer peripherals. The main goal of this project was to turn raw sales data into a simple and interactive dashboard that makes it easier to understand sales performance and identify useful business insights.

I worked on the data cleaning and transformation first and then used Power BI to create different visualizations, KPIs, and filters for analysis.

---

## 📌 About the Project

The Peripheral Sales Dashboard helps in understanding sales performance from different perspectives such as products, regions, and time periods.

Instead of looking through rows of raw data, the dashboard provides a visual way to quickly identify sales trends, compare performance, and understand which areas are performing well.

This project was created as part of my learning and portfolio work in **Data Analytics and Business Intelligence**.

---

## 🔄 My Approach

I followed a simple data analytics workflow while building this project:

**Raw Data → Data Cleaning → Data Transformation → Analysis → Visualization → Insights**

### 1. Data Cleaning

First, I worked on preparing the raw dataset for analysis. This included checking the data, handling unnecessary or missing values, correcting data types, and making the data more suitable for visualization.

### 2. Data Transformation

I used **Power Query** to transform the data and prepare the required fields for analysis.

### 3. Creating Measures

I used **DAX** to create the required calculations and KPIs for the dashboard.

### 4. Building the Dashboard

After preparing the data, I created different visualizations in Power BI to represent the sales information clearly.

The dashboard includes different charts, KPI cards, filters, and slicers that allow users to explore the data interactively.

---

## 📊 Dashboard Analysis

The dashboard can be used to analyze:

### Sales Performance

The overall sales performance can be viewed through KPIs and visualizations, making it easier to understand the current state of sales.

### Product Analysis

Different products can be compared to understand which products are performing better and which ones have comparatively lower sales.

### Regional Analysis

Sales can also be analyzed based on different regions to understand how performance varies geographically.

### Sales Trends

The dashboard allows sales performance to be viewed over time, which helps in identifying changes and trends in the data.

### Interactive Filters

Slicers and filters make it possible to select specific products, regions, or time periods and analyze the data accordingly.
